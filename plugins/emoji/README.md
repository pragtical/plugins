# Emoji

Pragtical plugin to quickly insert emoji via text description.
[Font Ligatures][ligatures] should be enabled along with a capable font.

Usage: Type `:monkey` to insert 🐒.

![preview](preview.webp)

`emoji.json` is acquired from [emojilib][emojilib] and licensed under MIT.

[ligatures]: https://pragtical.dev/docs/user-guide/font-ligatures#enable-ligatures
[emojilib]: https://github.com/muan/emojilib
